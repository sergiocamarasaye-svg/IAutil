Herramientas de IA

Fichas orientativas por categoría para encontrar por dónde empezar.

Las funciones, precios, planes gratuitos y condiciones cambian con frecuencia. No los indicamos aquí porque no podemos garantizar que estén actualizados: consulta siempre la web oficial de cada herramienta. Las ventajas y limitaciones descritas son generales y no sustituyen una prueba propia.

Asistentes de IA

ChatGPT

Qué es: Asistente conversacional de OpenAI.

Qué puedes hacer: Conversar, redactar, resumir y analizar textos que pegues.

Útil para: Redactar, resumir, explicar y generar ideas.

Ejemplo: Pedir un borrador de correo y ajustarlo con indicaciones.

Ventaja: Sirve para muchas tareas de texto en una sola herramienta.

Limitación: Puede dar respuestas erróneas con apariencia de seguridad; las funciones dependen del plan.

Versión gratuita y precios: no verificados aquí; consúltalos en la web oficial.

Web oficial de ChatGPT

Claude

Qué es: Asistente conversacional de Anthropic.

Qué puedes hacer: Redactar, resumir y analizar textos o documentos largos.

Útil para: Trabajar con textos largos, redactar y analizar documentos.

Ejemplo: Subir un informe y pedir un resumen con puntos pendientes.

Ventaja: Pensado para conversar y trabajar con textos extensos.

Limitación: Puede equivocarse; hay que verificar datos y citas.

Versión gratuita y precios: no verificados aquí; consúltalos en la web oficial.

Web oficial de Claude

Gemini

Qué es: Asistente de Google.

Qué puedes hacer: Consultas, redacción e ideas, con integración en servicios de Google.

Útil para: Consultas, redacción y trabajo junto a servicios de Google.

Ejemplo: Preparar un esquema de presentación.

Ventaja: Encaja bien si ya usas una cuenta de Google.

Limitación: Las funciones pueden variar según cuenta, país y plan.

Versión gratuita y precios: no verificados aquí; consúltalos en la web oficial.

Web oficial de Gemini

Estudio y aprendizaje

NotebookLM

Qué es: Herramienta de Google para trabajar sobre las fuentes que tú subes.

Qué puedes hacer: Subir tus propias fuentes y hacer preguntas o resúmenes sobre ellas.

Útil para: Resumir y hacer preguntas sobre tus propios documentos.

Ejemplo: Subir apuntes y pedir un resumen y preguntas de repaso.

Ventaja: Trabaja sobre tus materiales, no sobre cualquier tema.

Limitación: La calidad depende de las fuentes; también puede equivocarse.

Versión gratuita y precios: no verificados aquí; consúltalos en la web oficial.

Web oficial de NotebookLM

Quizlet

Qué es: Plataforma de estudio con tarjetas y pruebas.

Qué puedes hacer: Crear y practicar tarjetas de estudio y pruebas.

Útil para: Memorizar vocabulario y conceptos.

Ejemplo: Crear tarjetas de un tema y practicar con ellas.

Ventaja: Facilita memorizar con práctica repetida.

Limitación: No es un asistente general; las funciones de IA o de pago pueden variar.

Versión gratuita y precios: no verificados aquí; consúltalos en la web oficial.

Web oficial de Quizlet

Creación de imágenes

Midjourney

Qué es: Generador de imágenes a partir de texto.

Qué puedes hacer: Generar imágenes a partir de una descripción escrita.

Útil para: Ilustraciones y conceptos visuales.

Ejemplo: Probar estilos para una portada.

Ventaja: Útil para explorar estilos visuales rápidamente.

Limitación: Controlar detalles concretos es difícil; revisa las condiciones de uso de lo generado.

Versión gratuita y precios: no verificados aquí; consúltalos en la web oficial.

Web oficial de Midjourney

Ventaja: Encaja con el ecosistema de Adobe.

Limitación: Los límites de uso dependen del plan; revisa las condiciones de uso.
